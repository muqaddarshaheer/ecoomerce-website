## Synopsis

Paperlane is a website for a shop that sells greeting cards, gifts, dolls, files, stationery, handbags, wallets, beauty products and small accessories. A visitor can look through the catalogue without creating an account. A registered customer can keep a cart, choose an address and a payment method, place an order, track it, cancel it before dispatch, and ask for a return or replacement within seven days of delivery.

The shop has three separate doors. Customers use the shop login. An administrator manages products, stock, staff, payments, returns, feedback, FAQs and reports. An employee sees orders that are ready to fulfil, records dispatch and delivery, and can change only that employee's own password.

Each product has a 7-digit product ID. Each order has a 16-digit order number built from the payment type, the primary product ID and a sequence. Card payment in this project is simulated and is labelled as such. Cheque clearance and cash-on-delivery collection are recorded by staff. The application does not store a full card number or CVV, and it does not call a real bank.
